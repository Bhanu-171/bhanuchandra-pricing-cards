# Project 03 — Responsive Product Pricing Cards

A sample SaaS pricing section made with HTML, CSS and JavaScript.

## Features
- Three plans: Starter, Pro and Team
- Monthly and yearly billing buttons
- Yearly prices are approximately 20% lower than monthly billing over 12 months
- Price values are stored in HTML `data-monthly` and `data-yearly` attributes
- Popular and Best Value ribbons
- CSS Grid layout, soft shadows, rounded cards and hover movement
- Reduced-motion support
- Keyboard-visible focus and accessible `aria-pressed` toggle buttons
- Responsive single-column layout below 800px

## Run
Open `index.html` in a browser, or use VS Code with the Live Server extension.

All plan names, prices and features are fictional, as requested in the learner guide.
